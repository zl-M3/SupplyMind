# 库存预警处理规范

## 库存状态定义

系统按商品总库存与该商品安全库存比较，划分三种状态：当前库存为 0 时为缺货；当前库存小于安全库存时为低库存；其余为正常。商品总库存等于所有仓库库存之和，缺货与低库存统一进入库存预警列表，缺货优先展示。

## 补货量计算口径

首期补货公式为：建议采购量 = max(0, 安全库存目标 - 当前可用库存 - 已审批未收货数量)。

其中当前可用库存指各仓库库存合计，已审批未收货数量指处于已审批与部分收货状态订单中尚未收货的数量。计算结果为 0 时表示无需补货。

系统当前没有销售历史数据，因此不得编造需求预测。任何补货建议都必须明确说明是按安全库存口径计算，不允许引入没有数据支撑的季节性系数或增长率。

## 处理优先级

缺货商品优先处理，其次是缺口较大的低库存商品。同一优先级内，按缺口从大到小排序。缺货商品应在 1 个工作日内完成下单，低库存商品应在 3 个工作日内完成补货决策。

## 库存变动与流水

所有库存变动都必须写入库存流水，记录变动类型、带符号的变动数量、变动后结存、业务来源单据号与操作人。采购入库记为正数，调拨出库记为负数，调拨入库记为正数。

库存更新与流水写入必须在同一事务内完成，禁止先改库存再补流水。

## 调拨规则

调拨前必须校验调出仓库的可用库存，库存不足时整个调拨操作失败。调出仓库与调入仓库不能相同。调拨确认后，一次性扣减调出仓库库存并增加调入仓库库存，同时生成调拨业务记录与两条库存流水。

## 预警升级

连续 3 天处于缺货状态的商品，自动升级为高优先级预警，需要在工作台显著位置提示，并由采购负责人确认处理方案。
