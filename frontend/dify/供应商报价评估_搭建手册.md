# Dify 工作流搭建手册：供应商报价评估

> 对应设计：`docs/采购AI助手设计.md` 中 **A2 询价比价** 的供应商侧扩展
> 目标：上传一份供应商报价单 → 三列基准对比 + 质量档位 + 二维判定 → 模型归因与议价策略 → 输出评估报告
>
> **核心分界**：所有数字由代码节点算死；LLM 只做「归因」和「议价策略」，且每条结论必须能指回具体行号。

---

## 〇、开始之前

### 0.1 建什么

Dify 控制台 → **创建应用** → 选 **工作流（Workflow）** → 空白工作流 → 命名 `供应商报价评估`。

### 0.2 两个必须提前确认的前提

| 前提 | 说明 |
|---|---|
| **模型已配置** | 每个 LLM 节点要选一个你实例里已接好的模型（`gpt-4o-mini` / `qwen-plus` / `deepseek-chat` 都行），温度设 0 或 0.1 |
| **文件格式用 CSV 优先** | Dify 的「文档提取器」对 **xlsx 支持不稳定**。**建议让供应商按模板另存为 CSV** 再上传。下面所有示例都是 CSV |

### 0.3 报价单模板（给供应商的）

```csv
商品编码,商品名称,单价,币种,含税,有效期
PRD-001,五层瓦楞纸箱,4.35,CNY,是,2026-12-31
```

第 1 列 **必须是我方商品编码**（`PRD-xxx`）——这是"供应商按我方模板填"的落地方式，也是匹配环节归零的前提。

---

## 一、节点总览（8 个）

```
开始 ──► 文档提取器 ──► LLM-1 结构化 ──► 代码-1 校验+三列基准
                                            │
                                            ▼
                                    代码-2 质量档位（按品类）
                                            │
                                            ▼
                                    代码-3 二维判定 + 锚点
                                            │
                                            ▼
                                    LLM-2 归因 + 议价策略
                                            │
                                            ▼
                                    LLM-3 生成报告 ──► 结束
```

| # | 节点名 | 类型 | 作用 | 用 LLM？ |
|---|---|---|---|---|
| 1 | 开始 | start | 收 supplier_id + 报价单文件 | — |
| 2 | 报价单解析 | 文档提取器 | CSV/文件 → 纯文本 | — |
| 3 | LLM-1 报价结构化 | LLM | 文本 → 严格 JSON 行数组 | ✅ |
| 4 | 代码-1 校验与基准 | 代码 | 校验编码、算三列差额 | — |
| 5 | 代码-2 质量档位 | 代码 | 最近 5 批 → A/B/C/D | — |
| 6 | 代码-3 判定与锚点 | 代码 | 二维矩阵 + 锚点/底线价 | — |
| 7 | LLM-2 归因与策略 | LLM | 挑异常、给先报/底线/理由 | ✅ |
| 8 | LLM-3 生成报告 | LLM | 输出 markdown 报告 | ✅ |
| 9 | 结束 | end | 输出报告 + 明细 JSON | — |

> 只有 3 个 LLM 节点。这就是「代码算数、模型解释」的分界线。

### 节点 3 · LLM-1「报价表结构化」

**输入**：`文档提取器 / text`

**系统提示词：**

```text
你是报价单解析器。你的唯一任务是把 CSV/表格文本转成严格 JSON。

规则：
1. 只输出 JSON，不要任何解释、不要 markdown 代码块。
2. 商品编码统一转成大写并去掉空格，格式必须是 PRD-数字。
3. 单价转成数字（去掉 ¥ 和千分位逗号）。无法识别的行放进 errors。
4. 不要编造任何一行；文本里没有的商品绝对不要输出。
5. 保留原始行号 row_no（从 1 开始，不含表头），便于回溯。

输出格式：
{
  "rows": [
    {"row_no": 1, "code": "PRD-001", "name": "五层瓦楞纸箱", "price": 4.35,
     "currency": "CNY", "tax_included": true, "valid_until": "2026-12-31"}
  ],
  "errors": [
    {"row_no": 5, "raw": "原始这一行的内容", "reason": "缺少商品编码"}
  ]
}
```

**用户提示词：**

```text
报价单原文：
{{#文档提取器.text#}}
```

**设置**：温度 0，最大 token 2000。

### 节点 4 · 代码-1「校验与三列基准」

**输入变量**（务必按这个名字建）：

| 变量名 | 值来源 |
|---|---|
| `rows_json` | `LLM-1 / text` |
| `supplier_id` | `开始 / supplier_id` |

**输出变量**：`rows`（字符串）、`errors`（字符串）、`stat`（字符串）

**Python 代码：**

```python
import json

# ============ 演示用基准数据 ============
# 接后端时：把这三段换成「HTTP 请求」节点的结果，代码逻辑不用改
OUR_PRICE = {
    "PRD-001": 4.2, "PRD-002": 28.5, "PRD-003": 6.8, "PRD-004": 45.0,
    "PRD-005": 22.5, "PRD-006": 1.2, "PRD-007": 38.0, "PRD-008": 32.0,
    "PRD-009": 1.8, "PRD-010": 5.5, "PRD-011": 12.0, "PRD-012": 18.5,
}
LAST_PRICE = {
    "PRD-001": 4.0, "PRD-002": 27.0, "PRD-003": 6.5, "PRD-004": 44.0,
    "PRD-005": 22.0, "PRD-006": 1.25, "PRD-007": 37.0, "PRD-008": 31.0,
    "PRD-009": 1.75, "PRD-010": 5.4, "PRD-011": 11.8, "PRD-012": 18.0,
}
PEER_MIN = {
    "PRD-001": 3.95, "PRD-002": 26.8, "PRD-005": 21.8,
    "PRD-006": 1.18, "PRD-010": 5.2, "PRD-012": 17.6,
}
CATEGORY = {
    "PRD-001": "包装材料", "PRD-002": "包装材料", "PRD-003": "包装材料",
    "PRD-004": "日用百货", "PRD-005": "办公耗材", "PRD-006": "办公耗材",
    "PRD-007": "化工原料", "PRD-008": "劳保用品", "PRD-009": "包装材料",
    "PRD-010": "包装材料", "PRD-011": "包装材料", "PRD-012": "包装材料",
}


def _pct(new, old):
    if not old:
        return None
    return round((new - old) / old, 4)


def main(rows_json: str, supplier_id: str) -> dict:
    try:
        payload = json.loads(rows_json)
    except Exception:
        return {"rows": "[]", "errors": json.dumps(
            [{"reason": "LLM 输出不是合法 JSON，请重跑或降低温度"}], ensure_ascii=False),
            "stat": "{}"}

    ok, bad = [], list(payload.get("errors") or [])

    for r in payload.get("rows") or []:
        code = str(r.get("code") or "").strip().upper()
        price = r.get("price")
        row_no = r.get("row_no")

        if code not in OUR_PRICE:
            bad.append({"row_no": row_no, "code": code,
                        "reason": "商品编码不在我方商品库"})
            continue
        try:
            price = float(price)
        except Exception:
            bad.append({"row_no": row_no, "code": code, "reason": "单价无法解析"})
            continue
        if price <= 0:
            bad.append({"row_no": row_no, "code": code, "reason": "单价必须大于 0"})
            continue

        our = OUR_PRICE[code]
        last = LAST_PRICE.get(code)
        peer = PEER_MIN.get(code)

        ok.append({
            "row_no": row_no,
            "code": code,
            "name": r.get("name"),
            "category": CATEGORY.get(code, "未分类"),
            "price": price,
            "our_price": our,
            "last_price": last,
            "peer_min": peer,
            "delta_vs_last": _pct(price, last),   # 纵向：涨跌
            "delta_vs_our": _pct(price, our),     # 对我方在用价
            "delta_vs_peer": _pct(price, peer),   # 横向：与同行最低价
        })

    stat = {
        "total": len(ok) + len(bad),
        "valid": len(ok),
        "rejected": len(bad),
        "supplier_id": supplier_id,
        "categories": sorted({x["category"] for x in ok}),
    }
    return {
        "rows": json.dumps(ok, ensure_ascii=False),
        "errors": json.dumps(bad, ensure_ascii=False),
        "stat": json.dumps(stat, ensure_ascii=False),
    }
```

### 节点 5 · 代码-2「质量档位」

**输入变量**：

| 变量名 | 值来源 |
|---|---|
| `supplier_id` | `开始 / supplier_id` |
| `stat` | `代码-1 / stat` |

**输出变量**：`grades`（字符串）

**Python 代码：**

```python
import json

# ============ 演示用质检记录 ============
# 接后端时换成 HTTP 节点：GET /api/quality-records?supplier_id=&category=&limit=5
QUALITY_RECORDS = [
    # SUP-001 包装材料：5 批，质量很好
    {"supplier_id": "SUP-001", "category": "包装材料", "batch": "B01", "inspected": 1000, "qualified": 998, "returned": 2, "complained": 0},
    {"supplier_id": "SUP-001", "category": "包装材料", "batch": "B02", "inspected": 800, "qualified": 796, "returned": 3, "complained": 0},
    {"supplier_id": "SUP-001", "category": "包装材料", "batch": "B03", "inspected": 1200, "qualified": 1196, "returned": 2, "complained": 1},
    {"supplier_id": "SUP-001", "category": "包装材料", "batch": "B04", "inspected": 900, "qualified": 897, "returned": 1, "complained": 0},
    {"supplier_id": "SUP-001", "category": "包装材料", "batch": "B05", "inspected": 1100, "qualified": 1094, "returned": 4, "complained": 0},
    # SUP-003 劳保用品：质量差
    {"supplier_id": "SUP-003", "category": "劳保用品", "batch": "C01", "inspected": 500, "qualified": 470, "returned": 18, "complained": 3},
    {"supplier_id": "SUP-003", "category": "劳保用品", "batch": "C02", "inspected": 600, "qualified": 561, "returned": 22, "complained": 4},
    # SUP-005 包装材料：只有 1 批 → 样本不足
    {"supplier_id": "SUP-005", "category": "包装材料", "batch": "D01", "inspected": 400, "qualified": 398, "returned": 1, "complained": 0},
]

WINDOW_BATCHES = 5   # 取最近 5 批
MIN_SAMPLE = 2       # 少于 2 批 → 数据不足


def main(supplier_id: str, stat: str) -> dict:
    try:
        cats = (json.loads(stat) or {}).get("categories") or []
    except Exception:
        cats = []

    grades = {}
    for cat in cats:
        rs = [r for r in QUALITY_RECORDS
              if r["supplier_id"] == supplier_id and r["category"] == cat]
        rs = rs[-WINDOW_BATCHES:]

        sample = len(rs)
        if sample < MIN_SAMPLE:
            grades[cat] = {"grade": "数据不足", "sample": sample,
                           "rate": None, "reason": "最近质检批次不足 %d 批" % MIN_SAMPLE}
            continue

        inspected = sum(r["inspected"] for r in rs)
        qualified = sum(r["qualified"] for r in rs)
        returned = sum(r["returned"] for r in rs)
        complained = sum(r["complained"] for r in rs)

        rate = qualified / inspected if inspected else 0
        ret_rate = returned / inspected if inspected else 0

        if rate >= 0.995:
            grade = "A"
        elif rate >= 0.985:
            grade = "B"
        elif rate >= 0.96:
            grade = "C"
        else:
            grade = "D"

        # 退货率 / 客诉触发降档
        if ret_rate > 0.01 or complained >= 2:
            grade = {"A": "B", "B": "C", "C": "D", "D": "D"}[grade]

        grades[cat] = {
            "grade": grade,
            "sample": sample,
            "rate": round(rate, 4),
            "return_rate": round(ret_rate, 4),
            "complaints": complained,
        }

    return {"grades": json.dumps(grades, ensure_ascii=False)}
```

### 节点 6 · 代码-3「二维判定 + 锚点」

**输入变量**：

| 变量名 | 值来源 |
|---|---|
| `rows` | `代码-1 / rows` |
| `grades` | `代码-2 / grades` |

**输出变量**：`rows_with_verdict`（字符串）、`summary`（字符串）

**Python 代码：**

```python
import json

# 二维判定矩阵：价格档 × 质量档
MATRIX = {
    "down":  {"A": "直接接受", "B": "直接接受", "C": "小议",               "D": "必须议价", "数据不足": "直接接受"},
    "flat":  {"A": "直接接受", "B": "直接接受", "C": "小议",               "D": "必须议价", "数据不足": "直接接受"},
    "up":    {"A": "直接接受", "B": "小议",     "C": "必须议价",            "D": "必须议价", "数据不足": "小议"},
    "bigup": {"A": "小议",     "B": "必须议价", "C": "必须议价",            "D": "建议换供应商", "数据不足": "必须议价"},
}

FLOOR_RATE = 0.97      # 底线价 = 锚点 × 0.97
OPEN_RATE = 0.95       # 先报价 = 锚点 × 0.95


def bucket_of(delta):
    """按相对上次报价的涨跌幅分档"""
    if delta is None:
        return "flat"
    if delta <= 0:
        return "down"
    if delta <= 0.05:
        return "flat"
    if delta <= 0.10:
        return "up"
    return "bigup"


def median(vals):
    vals = sorted(vals)
    n = len(vals)
    if n == 0:
        return None
    return vals[n // 2] if n % 2 == 1 else (vals[n // 2 - 1] + vals[n // 2]) / 2


def main(rows: str, grades: str) -> dict:
    rows = json.loads(rows or "[]")
    grades = json.loads(grades or "{}")

    out = []
    for r in rows:
        cat = r.get("category")
        g = (grades.get(cat) or {}).get("grade", "数据不足")
        b = bucket_of(r.get("delta_vs_last"))
        verdict = MATRIX[b][g]

        # 锚点：上次报价 / 我方在用价 / 同行最低 三者取中位数（代码算，不给模型）
        cands = [x for x in [r.get("last_price"), r.get("our_price"), r.get("peer_min")] if x]
        anchor = round(median(cands), 2) if cands else round(r["price"], 2)

        out.append({
            **r,
            "grade": g,
            "price_bucket": b,
            "verdict": verdict,
            "anchor_price": anchor,
            "open_price": round(anchor * OPEN_RATE, 2),
            "floor_price": round(anchor * FLOOR_RATE, 2),
            "quality_note": "本行未参与质量联动（样本不足）" if g == "数据不足" else "",
        })

    histogram = {}
    for r in out:
        histogram[r["verdict"]] = histogram.get(r["verdict"], 0) + 1

    summary = {
        "valid_rows": len(out),
        "by_verdict": histogram,
        "need_negotiation": sum(v for k, v in histogram.items() if k in ("必须议价", "建议换供应商")),
        "total_amount_now": round(sum(r["price"] for r in out), 2),
        "total_amount_anchor": round(sum(r["anchor_price"] for r in out), 2),
    }

    return {
        "rows_with_verdict": json.dumps(out, ensure_ascii=False),
        "summary": json.dumps(summary, ensure_ascii=False),
    }
```

### 节点 7 · LLM-2「归因 + 议价策略」

**输入**：`代码-3 / rows_with_verdict`、`代码-3 / summary`、`代码-1 / errors`、`开始 / buyer_note`

**系统提示词：**

```text
你是资深采购谈判顾问。数据已经由系统算好，你只做三件事，绝不重新算数。

【你可以做的】
1. 归因：解释异常行可能的原因（原材料涨价 / 规格变化 / 汇率 / 报价口径从含税变不含税 / 数量差异等）
2. 挑选：从全部行里挑出最值得优先谈的 3～5 行
3. 给策略：每行给「先报价 / 底线价 / 一句话理由」

【你绝对不能做的】
- 不能修改任何数字（price / anchor_price / open_price / floor_price 原样引用）
- 不能编造数据里没有的商品或商品编码
- 不能断言数据之外的因果（比如"因为最近石油涨价"必须有依据；没依据就说"推测"）

【输出格式】严格 JSON：
{
  "headline": "一句话总体判断",
  "priority_rows": [
    {
      "code": "PRD-002",
      "why": "归因，必须引用具体数字",
      "open_price": 26.8,
      "floor_price": 27.4,
      "talking_point": "一句话话术"
    }
  ],
  "quality_risk": "质量相关的风险提示，无则填 null",
  "rejected_rows_note": "被拒行的说明，无则填 null"
}
```

**用户提示词：**

```text
供应商：{{#开始.supplier_id#}}
采购员备注：{{#开始.buyer_note#}}

逐行判定结果（已算好，直接引用）：
{{#代码-3.rows_with_verdict#}}

汇总：
{{#代码-3.summary#}}

被拒绝的行：
{{#代码-1.errors#}}
```

**设置**：温度 0.2（允许一点措辞变化，但不许改数字）。

### 节点 8 · LLM-3「生成报告」

**输入**：`代码-3 / rows_with_verdict`、`LLM-2 / text`、`代码-1 / stat`、`代码-2 / grades`

**系统提示词：**

```text
你是采购分析报告撰写者。把已有结论整理成一份中文 Markdown 报告。

结构固定：
## 一、结论摘要
（3 行以内，含：本次报价总体涨跌、需议价行数、质量风险）

## 二、三列基准对比
Markdown 表格，列：商品编码 | 商品名 | 本次报价 | 比上次报价 | 比我在用价 | 比同行最低 | 质量档 | 判定
- 百分比保留一位小数，涨用 ↑，跌用 ↓
- 数据为 null 的填 "—"

## 三、优先议价清单
（逐行：商品 + 锚点/先报/底线 + 理由）

## 四、质量风险
（按品类列档位与样本量；标出"数据不足"的品类）

## 五、异常与拒收行
（列出未通过校验的行及原因）

要求：不要编造数字；表格里的每个数字都必须来自输入。
```

**用户提示词：**

```text
统计：{{#代码-1.stat#}}
质量档位：{{#代码-2.grades#}}
逐行明细：{{#代码-3.rows_with_verdict#}}
汇总：{{#代码-3.summary#}}
归因与策略：{{#LLM-2.text#}}
```

## 三、测试用例（直接用这份 CSV）

```csv
商品编码,商品名称,单价,币种,含税,有效期
PRD-001,五层瓦楞纸箱,4.35,CNY,是,2026-12-31
PRD-002,气泡膜卷,32.00,CNY,是,2026-12-31
PRD-003,食品级PE保鲜袋,6.90,CNY,是,2026-12-31
PRD-005,A4复印纸,21.50,CNY,是,2026-12-31
PRD-099,未知商品,9.90,CNY,是,2026-12-31
```

**预期结果（用来自查是否搭对）：**

| 商品 | 本次 | 上次 | 涨跌 | 同行最低 | 质量档 | 应得判定 |
|---|---|---|---|---|---|---|
| PRD-001 | 4.35 | 4.00 | **+8.75%** | 3.95 | A（5 批，99.7%） | 直接接受 |
| PRD-002 | 32.00 | 27.00 | **+18.5%** | 26.80 | A | **小议**（bigup×A） |
